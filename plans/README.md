## Findings considered and NOT turned into plans

Surfaced by the audit, deliberately deferred or rejected (recorded so they
aren't re-audited next run):

- **CI supply-chain hardening** (pin GitHub Actions to commit SHAs in
  `release.yml`; add `cargo audit`/`cargo-deny`; run `test:fixtures` +
  `shot:check` in CI): real and worth doing, but the owner chose not to scope
  it into this batch. `release.yml` uses floating tags
  (`tauri-apps/tauri-action@v0`, `dtolnay/rust-toolchain@stable`) with signing
  secrets in scope — highest-value supply-chain target if revisited. NOT
  rejected, just deferred.
- **CSP tightening** (`src-tauri/tauri.conf.json` `connect-src`/`img-src`/
  `media-src` allow bare `https:`/`http:`; `script-src` has `'unsafe-eval'`):
  defense-in-depth that would contain plans 001/002's threat model, but needs a
  frontend regression pass across all loaders (some may need remote origins /
  eval) before tightening. Deferred — do it alongside the error-experience
  (B1–B8) work when the loader surface is being touched anyway.
- **Vite dev-server advisory** (GHSA-fx2h-pf6j-xcff, high, Windows
  `server.fs.deny` bypass): dev-only devDependency; bump `vite` within the
  existing `^7.1.3` range to `>=7.3.5`. A one-line lockfile change, not worth a
  plan — do it in the next dependency-maintenance pass. Runtime is unaffected.
- **Dual lockfiles** (`package-lock.json` + `pnpm-lock.yaml` both tracked;
  actual `node_modules` is a pnpm store while CI uses `npm ci`): drift risk,
  currently in sync by hand. Resolve by picking one manager — a decision for
  the owner, not an executor plan.
- **`@yohawing/three-mmd-loader` pinned to 0.4.0 while 0.6.0 exists**: already
  tracked in `TODO.md` ("次の実装キュー" #7). Not re-planned.
- **`geometry.rs:496` panic TODO is stale**: the audit confirmed the
  out-of-range skin-slice was fixed in commit `06930d1` (clamp at
  `geometry.rs:489-500`). No code change needed; the `TODO.md` note should be
  removed and (optionally) a regression test added replaying the
  `usd-humanfemale-walk` mismatched-length case, modeled on the existing
  `negative_face_counts_are_rejected` test.
- **Architecture-review-2026-07 backlog** (store selector migration, god-file
  splits, IPC type-gen expansion, dispose audit, glam adoption, backend shared
